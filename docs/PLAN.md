# 문서 자동화 계획과 공개 범위

원본 양식과 참고자료는 사용자가 로컬에서 제공하며 읽기 전용으로 다룬다. 공개 저장소는 재사용 코드·스킬·서식 규칙·SHA 핀·독립 합성 입력만 포함한다. 원문 추출·원사업 비교·실제 출력·검토 이력은 [비공개 로컬 자료](PRIVACY.md)이며 새 checkout에 포함하지 않는다.

| 계층 | 범위 | 검증 경계 |
|---|---|---|
| 양식 분석 | 구조·서식·작성지침·반복단위·개체 식별 | 지정한 원본 SHA와 XML 위치에 한정 |
| 참고 분석 | 문체·정보 구성·대응·반례 분리 | 원사업 사실·개별 관측은 비공개 입력 |
| 공통 사실 | 값·타입·출처·상태·문서 간 직접 연결 | 실제 수행·승인·서명을 추론하지 않음 |
| 작성·생성 | HWPX 보존, 역할별 프로필·스킬과 19종 초안 | 34서식의 전체 생성·출력 실증과 구분 |
| 출력 QA | 현재 bytes·실제 앱·PDF·모든 페이지 관측 | 과거 기록이나 테스트 통과로 대체하지 않음 |

실제 사업 정보가 없는 예제에는 문서 안에도 합성 고지를 표시한다. 공개 합성 fixture는 원사업 추출값의 익명화본이 아니라 별도로 작성한 가정과 설계 시안이다. 실제 결과·측정·집행·승인·서명을 만들지 않는다.

현재 문서 품질 개선 반복은 사용자 요청으로 중단된 상태다. 구현·회귀와 과거 로컬 검토 범위를 전체 문서 품질 완료 또는 95% 달성으로 해석하지 않는다. 작업을 다시 시작할 때는 별도 요청과 현재 입력·코드·프로필·출력 SHA에 근거해 미검토 범위를 명시한다.
