# 서식·편집 개선의 범위

현재 문서 품질 개선 반복은 중단된 상태다. 공개 저장소는 구현·프로필·스킬과 독립 합성 예제를 제공하며, 실제 기업의 참고 원문·같은 문안 비교 입력·한컴 PDF/PNG·수동 관측과 과거 판정은 비공개 로컬 자료로 분리한다. [공개·비공개 정책](PRIVACY.md)을 따른다.

역할별 글꼴·크기·행간·표지 계층·본문/표 배치, 계속 쪽 ID·시험 케이스·관리표의 라벨/값 구분은 지정 원본 SHA와 명시 owner/selector 범위에서 적용한다. 한 전문가 사례의 오류·작은 글자·극단적 여백·업무값을 보편 규칙으로 삼지 않는다. 입력의 값·타입·출처·미확인 상태와 개체는 보호한다.

참고 그림 인용과 전체 원본을 보존한 부분 보기는 [인용 계약](REFERENCE_QUOTATIONS.md)을 따른다. 원문 소유자와 출처를 검증하는 기능이며 실제 새 사업의 시험·설치·승인 사실을 생성하는 기능이 아니다. 비공개 관측·원문 선택 JSON은 별도로 제공하며 결과를 공개 source 폴더에 쓰지 않는다.

실제 출력 검토는 현재 생성 bytes, 실제 한컴 버전과 사건, 재열기한 HWPX, PDF·모든 페이지 PNG, 검토자와 관측 범위를 연결해야 한다. 과거 검토 수치·스크린샷·해시 목록을 새 출력 판정으로 재생성하지 않는다. 공개 기본 회귀나 프로필 선택은 이 검토를 대신하지 않는다.

전체 19종·모든 평가 기준 또는 참고 수준 95% 달성을 선언하지 않는다. 개별 서식 기준, 실제 자료 충족·필수 artifact, 내용·값/타입·출처 대응, 그림 판독성과 실제 사업 제출 여부는 별개다. 미검토·자료 부재·중대 결함을 점수 통과나 사후 면제로 바꾸지 않는다. 구체적 과거 QA와 남은 쟁점은 원래 비공개 로컬 이력에 보존한다.
