# 공개 문서 자동화 자원

이 폴더는 원본 양식의 ID·SHA와 명시 지침, 선별한 일반 작성 규칙, 활성 서식 목표·정확한 양식 guard 및 필요한 스타일 측정값을 보관한다. 실제 기업·개인·연락처·사업 일정·승인·실적·장비 식별값, 참고자료 전량 추출과 과거 실행 산출물은 배포하지 않는다. 원문 사실을 이름만 바꿔 합성 예제로 재분류하지 않는다.

양식 지침·일반화한 작성 권고·구현 선택·미확인을 구분하며 한 전문가 사례를 보편 규칙으로 승격하지 않는다. 원본 ID·SHA·XML 위치는 보존하되 원문 파일명과 개인별 로컬 경로는 비공개 설정에서 해결한다. `--template-root`, 환경 설정 또는 SHA를 검증하는 로컬 source map으로 실제 양식을 준비한다. 문서별 숫자 서식 ID는 해당 원본의 정의로만 해석한다.

`stage1/`은 양식과 명시 지침, `stage2/`는 일반화한 작성 지침·역할/해시 관계, `style-upgrade/`는 후보 서식·원문 위치·글꼴/기하 측정값을 보관한다. 참고 원문 literal과 전체 원본별 레코드는 비공개 보관 자료에서만 확인한다. `migration.json`은 현재 공개 자원의 SHA를 가리키며 과거 비공개 자료의 hash는 그 바이트가 공개됐다는 뜻이 아니다.

공개 자원만으로 실제 수행·설치·승인·측정이나 새 출력의 품질을 확정하지 않는다. 원본과 실행 엔진·폰트·실제 사업 입력 및 현재 바이트의 네이티브 검토는 별도 준비한다.
