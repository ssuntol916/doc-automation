# 분석·설계 작성 지침

공개 배포본은 일반화한 작성 지침만 포함한다. 실제 기업·담당자·연락처·사업 일정·성과·승인·장비 식별값과 원문 전량 추출·개별 판정은 비공개 보관 자료에 남긴다. 이름을 바꿔 합성 사실로 재분류하지 않는다.

선별 지침은 [analysis-design-patterns.json](analysis-design-patterns.json)에 있다. 원본 양식의 명시 지침, 전문가 사례의 관찰, 구현 선택과 미확인은 구분한다. 공개된 정적 자원만으로 실제 사업 증빙이나 현재 출력 품질의 충족을 선언하지 않는다.
